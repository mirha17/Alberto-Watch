ALBERTO WATCH COMPANY - FINAL WEBSITE (Beige + Dark Brown)
HOW TO RUN: open index.html in Chrome/Edge (internet needed for Bootstrap, jQuery, fonts, icons, weather, map).
For location in the ticker use VS Code "Live Server".

PAGES: index, collections, technology, gallery, store-locator, support, about, contact, sitemap (.html)
css/style.css  -> site theme (colours at the top as CSS variables)   css/member3.css -> technology/gallery/support styles
js/main.js     -> navbar, collections (search/filter/sort/popup), store locator, contact form
js/member3.js  -> visitor counter, ticker, clocks, gallery, support, repair tracker
js/products.js -> 40 products (JSON format)   js/data.js -> tech, gallery, FAQ, store hours, repair tickets

HOME PICTURES: images/home/slide1.jpg, slide2.jpg, slide3.png (slider + collection cards; About page uses slide2.jpg)
